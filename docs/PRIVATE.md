# Private documentation

The **`docs/_private/`** directory is listed in `.gitignore` and is not part of the public repository.

It holds working materials that are outside the product spec, for example:

- milestone roadmap with M0–M6 checkboxes (`product/milestones.md`)
- tech debt and repo conventions (`engineering/tech-debt.md`, `meta/conventions.md`)
- VPS/TLS runbooks and portfolio notes (`portfolio/`)
- personal notes (career KB, deploy secrets, `reuse-from-chainwise.md`)

**Public documentation** is everything else under `docs/` (see [README.md](README.md)): SRS, platform, pipeline, ADRs, API, screenshots.

After cloning, create `docs/_private/` locally or restore it from your own backup.
