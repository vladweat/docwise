# Конфигурация

Серверная часть читает переменные среды через `app.core.config.Settings`. Файл `.env` загружается
Pydantic Settings и Compose; параметры в `docker-compose.yml` могут переопределять его.
Не добавляйте `.env` и действующие ключи в Git. Безопасный файл-заготовка — `.env.example`.

## Среда выполнения и данные

| Переменная | Значение по умолчанию в `Settings` | Назначение |
| --- | --- | --- |
| `ENVIRONMENT` | `development` | Управляет проверками рабочего режима и доступностью OpenAPI и маршрута диагностики поиска |
| `LOG_LEVEL` | `INFO` | Уровень JSON-журналов серверной части |
| `DATABASE_URL` | локальный адрес PostgreSQL | URL подключения SQLAlchemy; Compose задаёт имя узла `postgres` |
| `DB_POOL_SIZE` | `10` | Размер основного пула соединений |
| `DB_MAX_OVERFLOW` | `20` | Дополнительные соединения пула |
| `REDIS_URL` | `redis://localhost:6379/0` | Сессии обновления доступа, ограничения частоты запросов, кэш и блокировки |
| `CELERY_BROKER_URL` | `redis://redis:6379/0` | Брокер Celery |
| `CELERY_RESULT_BACKEND` | `redis://redis:6379/0` | Хранилище результатов Celery |
| `S3_ENDPOINT` | `http://localhost:9000` | Адрес S3-совместимого хранилища MinIO |
| `S3_REGION` | `us-east-1` | Регион подписи запросов S3 |
| `S3_BUCKET_POLICY_SUPPORTED` | `true` | Проверять при готовности приложения, что доступ к бакету S3 закрыт политикой |
| `S3_ACCESS_KEY` | `docwise` | Ключ доступа S3; в рабочей среде это секрет |
| `S3_SECRET_KEY` | заполнитель | Секретный ключ S3; обязательно заменить |
| `S3_BUCKET` | `documents` | Закрытый бакет с оригиналами документов |
| `EMBEDDING_MODEL_PATH` | пусто | Каталог моделей ONNX; Compose задаёт `/app/.models` |

`POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB`, `MINIO_ROOT_USER` и
`MINIO_ROOT_PASSWORD` читаются сервисами Compose, а не `Settings`. Значения по умолчанию в
Compose предназначены только для локальной среды.

`DOCWISE_RLS_SESSION_ROLE` читается напрямую в `app.core.rls`, поэтому не входит в `Settings`.
Базовая конфигурация и профиль публичной демонстрации Compose передают `docwise_rls` серверной части,
фоновому обработчику и Beat. Одноразовый `db-migrate` создаёт или проверяет роль и выдаёт разрешения
до запуска этих процессов. За пределами поддерживаемых профилей Compose оператор должен настроить
эту роль и самостоятельно проверить `SET LOCAL ROLE`.

Не подключайте среду выполнения к PostgreSQL от имени суперпользователя без этой переменной: такая учётная
запись всегда обходит RLS.
Подробнее: [tenancy.md](../platform/tenancy.md#postgresql-rls).

## Аутентификация, cookie и изоляция организаций

| Переменная | Значение по умолчанию | Назначение и требования |
| --- | --- | --- |
| `SECRET_KEY` | небезопасный placeholder | Подпись JWT; запуск в рабочем режиме отклоняется при значении по умолчанию |
| `ALGORITHM` | `HS256` | Алгоритм JWT |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | `15` | Срок действия токена доступа |
| `REFRESH_TOKEN_EXPIRE_MINUTES` | `10080` | Срок действия токена обновления, 7 суток |
| `GOOGLE_CLIENT_ID` | пусто | Проверка идентификационного токена Google |
| `COOKIE_SAMESITE` | `none` | Атрибут SameSite для `dw_access`/`dw_refresh` |
| `COOKIE_SECURE` | `true` | Требовать защищённые cookie |
| `CORS_ORIGINS` | источники localhost | Список разрешённых источников запросов через запятую |
| `FRONTEND_URL` | пусто | Общедоступный адрес клиентской части; если не задан, используется первый источник из `CORS_ORIGINS` |
| `PLATFORM_HOST_SUFFIXES` | `localhost,docwise.app` | Разрешённые окончания имён узлов организаций |
| `SSO_PROVIDER` | `dev` | Доступна только тестовая заготовка `dev`; адаптера SAML/OIDC для рабочей среды нет |
| `SSO_FRESH_TTL_SECONDS` | `900` | Срок действия признака недавней проверки SSO в Redis |

В коде нет адаптера SAML/OIDC для производственной среды: любое значение `SSO_PROVIDER`, кроме
`dev`, не подключает внешнего поставщика удостоверений, а общедоступные маршруты SSO возвращают `404`.
Профиль публичной демонстрации явно отключает тестовую заготовку.

## Загрузка, поиск и языковая модель

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `UPLOAD_MAX_BYTES` | `52428800` | Максимальный размер PDF/DOCX, 50 MiB |
| `RATE_LIMIT_UPLOAD_PER_MINUTE` | `10` | Число загрузок в минуту для одного пользователя |
| `RATE_LIMIT_CHAT_PER_MINUTE` | `30` | Число запросов к чату в минуту для одного пользователя |
| `RATE_LIMIT_AUTH_PER_MINUTE` | `20` | Число запросов входа, регистрации и Google в минуту с одного IP-адреса |
| `RATE_LIMIT_TRUST_X_FORWARDED_FOR` | `false` | Доверять XFF только за настроенным прокси; включать, лишь если API недоступен напрямую |
| `AUDIT_LOG_RETENTION_DAYS` | `90` | Срок хранения журнала поиска и комментариев к отзывам; минимум 1 день |
| `RERANK_THRESHOLD` | `0.25` | Минимальная оценка sigmoid для повторного ранжирования |
| `HNSW_ITERATIVE_SCAN` | `relaxed_order` | Режим поиска по индексу PostgreSQL pgvector |
| `HNSW_MAX_SCAN_TUPLES` | `20000` | Максимум проверяемых записей при итеративном поиске HNSW |
| `OPENAI_API_KEY` | пусто | Секретный ключ совместимого с OpenAI API |
| `OPENAI_BASE_URL` | пусто | Необязательный базовый адрес совместимого шлюза |
| `OPENAI_MODEL` | пусто | Необязательное имя модели |
| `ENABLE_SEARCH_INSPECT` | вычисляется | Если значение не задано, функция включена, когда `ENVIRONMENT` не равен `production`, и выключена при `ENVIRONMENT=production` |

Клиент в `app.services.chat.llm` использует HTTP API, совместимый с OpenAI. Отдельного адаптера
Anthropic нет. Если ограничение частоты настроено, недоступность Redis приводит к HTTP 503:
запрос не пропускается при сбое проверки. `X-Forwarded-For` игнорируется, пока явно не разрешено доверять этому заголовку через
`RATE_LIMIT_TRUST_X_FORWARDED_FOR`; профиль публичной демонстрации включает его только при закрытом порте API и
единственной внешней точке входа через Caddy. Caddy по умолчанию очищает входящие значения
X-Forwarded-* от недоверенного клиента.

Зависимости серверной части устанавливаются из `backend/requirements.lock`. Чтобы обновить
закреплённые версии после изменения `requirements.txt`, создайте временное виртуальное окружение
Python 3.12, установите в нём диапазоны из `requirements.txt` и запишите результат командой
`python -m pip freeze --all > requirements.lock`; затем проверьте файл фиксации версий чистой установкой.
Скрипт сборки использует только lock-файл.

## Наблюдаемость и клиентская часть

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `SENTRY_DSN` | пусто | Включает Sentry SDK; без DSN интеграция отключена |
| `API_BASE_URL` | `http://localhost:8001` в Compose | Адрес API для среды выполнения, передаётся серверу клиентской части при запуске контейнера |
| `NEXT_PUBLIC_GOOGLE_CLIENT_ID` | пусто | Общедоступный идентификатор Google, встраивается при сборке |
| `NEXT_PUBLIC_SHOW_DEMO_LOGINS` | не задано | Явно показывает тестовые данные для входа; на localhost они показываются автоматически |

`HTTP_PROXY`, `HTTPS_PROXY`, их варианты в нижнем регистре и `NO_PROXY` передаются Compose в серверную
часть и фоновый обработчик. Внутренние имена узлов `postgres`, `redis`, `minio` должны оставаться в `NO_PROXY`.

## Переменные только для оценки

Compose задаёт серверной части:

- `EVAL_DIR=/eval`;
- `EVAL_DATASET=/eval/golden_dataset.json`;
- `EVAL_REPORT=/reports/rag_benchmark.md`;
- `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`;
- `LD_LIBRARY_PATH=/usr/local/lib`.

Первые три используются инструментами оценки, а не `Settings`. Флаги автономного режима запрещают
среде выполнения загружать модели из Hugging Face.

## Профили среды

- **Локальная среда/Compose:** `BILLING_PROVIDER=dev`, `SSO_PROVIDER=dev`, диагностика поиска включена,
  порты узлов привязаны к loopback, серверная часть работает с `--reload`.
- **Тестовая среда/CI:** отдельные службы PostgreSQL и Redis, отдельная база `docwise_test`, MinIO не запускается,
  ключ языковой модели не задан, внешние вызовы подменяются или отключаются.
- **Публичная демонстрация:** `ENVIRONMENT=production`, отдельная роль RLS и отдельная задача миграции;
  TLS и закрытие внутренних портов добавляет `docker-compose.public-demo.yml`. `SSO_PROVIDER=disabled`,
  `BILLING_PROVIDER=dev`, хранилище — одноузловой Garage.
- **Другая рабочая среда:** OpenAPI и диагностика поиска по умолчанию выключены; значение `SECRET_KEY` по умолчанию
  блокирует запуск. Compose запускает миграции отдельно и использует роль RLS без прав суперпользователя;
  отдельно нужно обеспечить TLS, секреты, резервное копирование и восстановление, сетевые правила,
  мониторинг и настоящего поставщика удостоверений или оплаты, если это требуется продукту.
