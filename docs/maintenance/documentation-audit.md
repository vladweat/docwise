## Что не является гарантией

`reports/rag_benchmark.md` — результат запуска от указанной в отчёте даты. Он не подтверждает качество
нового корпуса или следующей версии модели. Публичная демонстрация работает на одном VPS с тестовыми данными и не обеспечивает высокую доступность.

Закрытые эксплуатационные инструкции из исключённого из Git каталога `docs/_private/` не входят в копию репозитория; см. [PRIVATE.md](../PRIVATE.md).
