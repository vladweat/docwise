## Исправлено в коде и Compose

| Область | Текущее состояние |
| --- | --- |
| PostgreSQL RLS | Базовый и публичный профили Compose задают `docwise_rls`; служба миграции создаёт роль и выдаёт разрешения; среда выполнения должна подключаться от имени роли без прав суперпользователя |
| Сеть | Порты базового профиля привязаны к loopback; публичный профиль направляет запросы к приложениям через Caddy |
| Миграции | Одна задача `db-migrate` выполняется до запуска API и фонового обработчика |
| Удаление объекта | Удаление записи PostgreSQL и запись в очередь `storage_deletions` фиксируются транзакционно; очистку S3 можно повторить |
| Восстановление очереди | CLI с предварительным просмотром показывает устаревшие задачи обработки; для применения нужен явный флаг |
| Повторы и блокировки | Обработка повторяется только после временных ошибок; блокировка Redis использует токен владельца |
| Чат в одной сессии | Второй активный поток получает `409`; разные сессии независимы |
| Ошибки API | HTTP API использует общий конверт `{ error: { code, message, details? } }` |
| Срок хранения аудита | Celery Beat ежедневно удаляет просроченные записи по `AUDIT_LOG_RETENTION_DAYS` |

Эти пункты больше не относятся к незакрытым задачам в исходном коде. Их эксплуатационную надёжность всё ещё следует проверять.
