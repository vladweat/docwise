# Каталог экспериментов и отчётов

Отчёты фиксируют отдельные запуски и не гарантируют качество на новых данных. Сначала сверяйте дату,
набор данных, профиль и ограничения в самом файле. Текущий статус критериев качества и каноническая
интерпретация метрик описаны в [оценке](../docs/product/evaluation.md).

## Исходные замеры и варианты-кандидаты

Новые артефакты `eval/run_eval.py` включают секцию `Run metadata` с revision, состоянием дерева, хешем набора,
профилем и безопасными идентификаторами моделей/параметров. Markdown-отчёт не выводит тексты случаев или произвольные
email. JSON из `--diagnostics-report` сохраняет прежние ключи верхнего уровня и добавляет `metadata`; в старых JSON
этого поля нет, что означает «не записано». Исторические файлы остаются без изменений.

- **Полный прогон 2026-11-09 на ревизии `44b3f42`:** [отчёт](rag_evaluation_2026-11-09_44b3f42.md). Профиль `current`, 92 случая,
  ошибок случаев нет. Положительные случаи: `Context Precision` — `0.996` (n=42), `Answer Relevance` — `0.770` (n=45),
  `Citation Support` — `1.000` (n=42), `Citation Reference Precision` — `0.980` (50/51 ссылок). Доля попаданий в целевой
  документ (`Target document hit rate`) — `0.911` при пороге `0.980`, поэтому quality gate не пройден. В отчёте от
  2026-11-01 значения первых трёх метрик были `0.952`, `0.725` и `0.930`; прямое сравнение некорректно: SHA-256 и размер
  набора, а также профиль моделей различаются. `Citation Reference Precision` в старом отчёте отсутствует. Этот запуск
  использовал `ENVIRONMENT=development` только в одноразовом контейнере оценки, чтобы загрузить фиксированный encoder
  русскоязычной `Answer Relevance`; S3-совместимое хранилище было Garage `v2.5.0` в изолированном Compose-проекте
  без опубликованных портов, поскольку образ MinIO из Quay ответил `401 Unauthorized`. Отчёт фиксирует
  `working_tree_dirty=true`.
- **Актуальная пара Top-4 / Top-2, 2026-11-01:** [сравнение и решение](rag_quality_corrected_classifier_comparison.md),
  [Top-4 JSON](rag_quality_corrected_classifier_baseline.json), [Top-2 JSON](rag_quality_corrected_classifier_top2.json).
  Это полный прогон на 132 случаях с одинаковым хешем набора данных. Критерии качества по точности контекста
  (`Context Precision`) и релевантности ответа на английском языке (`English Answer Relevance`) не пройдены;
  Top-2 отклонён. В обоих JSON `code_revision=unrecorded`, поэтому
  побайтовая воспроизводимость не подтверждена.
- [Разбор причин непройденных критериев качества](rag_quality_failure_analysis.md) связывает релевантность ответа на английском языке (`English Answer Relevance`)
  с отказами на положительных случаях и показывает, как оценённая судьёй релевантность контекстов падает
  на более поздних рангах MIRACL.
- [Диагностика Task 3](rag_quality_task3_diagnostic.md) — более ранний исходный замер поиска и генерации,
  варианты-кандидаты профиля и ограничения VPS; результаты исторические относительно парного прогона выше.
- [Замер RAG](rag_benchmark.md) и [мультиязычный вариант-кандидат](rag_candidate_multilingual.md) — прежние
  полные запуски с другими наборами данных, настройками или классификацией отказов. Не сравнивайте их оценки
  напрямую с текущим парным прогоном.

## Содержимое и ограничения

Последние JSON для Top-4/Top-2, отчёт о сравнении, разбор провалов и новые диагностические JSON не содержат
вопросов, ответов, запросов к модели, текста документов или фрагментов. Это не означает, что старые отчёты
содержат только агрегаты или полностью обезличены. В частности, поля с вопросами для отдельных случаев есть
в следующих архивных отчётах: [замер RAG](rag_benchmark.md), [мультиязычный вариант-кандидат](rag_candidate_multilingual.md),
[вариант-кандидат MIRACL](rag_miracl_candidate.md), [диагностика этапов MIRACL](rag_miracl_stage_diagnostic.md),
[порог `0.10`](rag_miracl_threshold_010.md), [параллельный запуск с порогом](rag_miracl_threshold_010_concurrent.md)
и [короткая проверка параллельной обработки](rag_miracl_concurrency_smoke.md). Не описывайте архив целиком как
содержащий только агрегаты или как полностью обезличенный.

Новые запуски `eval/run_eval.py` исключают вопросы/ожидаемые ответы, ответы генерации, тексты фрагментов и email
учётных записей из публичного Markdown; диагностический JSON содержит только существующие безопасные метрики,
идентификаторы случаев и ranks. Секреты и service endpoints не входят в metadata. Не публикуйте исторические отчёты,
которые перечислены выше, как обезличенные без отдельной проверки.

Новые отчёты также показывают детерминированную точность inline-ссылок на найденные страницы и разделы. Она проверяет
только совпадение названия и местоположения ссылки с найденными источниками; семантическую поддержку утверждения отдельно
оценивает метрика `Citation support` на основе LLM. В Markdown и диагностическом JSON сохраняются только оценки и счётчики,
без текста ссылок, ответов и источников. Полный evaluation с LLM-судьёй требует отдельного запуска и не выполняется unit-тестами.

Подготовленные фрагменты MIRACL находятся только в игнорируемом `eval/local_data`; в этот каталог и Git они
не включены.
